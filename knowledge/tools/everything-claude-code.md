Comprehensive open-source Claude Code setup — 27 agents, 64 skills, 33 commands, and a built-in AgentShield security layer with 1,282 security tests. Designed to handle planning, code review, bug fixes, TDD, token optimization, and more. Works across Claude Code, Cursor, OpenCode, and Codex CLI — one repo replaces weeks of setup time.

## Key Features

- 27 pre-built agents for specialized tasks (planning, review, debugging, etc.)
- 64 reusable skills covering the full development lifecycle
- 33 commands for common workflows
- AgentShield: 1,282 security tests built in for safer agent operations
- Cross-editor support: Claude Code, Cursor, OpenCode, Codex CLI
- 100% free and open-source (MIT licensed)
